# G|E Recupera

Revenue Intelligence para identificação, priorização e recuperação de receita.

- Cadastro de oportunidades

- Priorização por valor, probabilidade e urgência
- Controle de acesso e validação server-side
- APIs e banco PostgreSQL

Ambiente operacional: Hatchable. Código espelhado neste diretório para versionamento técnico.
