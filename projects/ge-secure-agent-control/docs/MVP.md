# MVP

1. Inventário de agentes.
2. Identidade e owner.
3. Registro de ferramentas/APIs/MCP.
4. Políticas allow/deny/approval.
5. Central de aprovação humana.
6. Log completo de execução.
7. Dashboard de risco, custo e atividade.
8. Kill switch.
9. Alertas de comportamento fora da política.
10. API/SDK para integrar agentes existentes.

## Critério de sucesso
No Cliente Zero, 100% dos agentes críticos inventariados; ações críticas passam pelo Approval Center; toda execução relevante possui correlation_id e trilha; custo é atribuível por agente e tenant.
