# G|E ONE Condo — Demo 0.1

Protótipo navegável para demonstração comercial e validação inicial de UX.

## Como visualizar
Baixe/clone o repositório e abra `ge-one-condo/demo/index.html` em um navegador moderno. Não requer build nesta versão.

## O que já funciona na demo
- Troca de persona/tela: Portaria, Síndico, Administradora, Trust e Discovery.
- Nova encomenda com leitura de etiqueta simulada.
- Escolha de tamanho.
- Sugestão de locker.
- BOX Anywhere para volume fora do locker.
- Confirmação de recebimento.
- Atualização da fila e contador.
- Feedback de notificação simulada.

## Importante
Esta versão usa dados fictícios e não possui autenticação, backend, banco, WhatsApp real, OCR real ou acionamento de hardware. É uma demonstração de produto/UX, não produção.

## Próxima etapa técnica
Transformar o fluxo demonstrativo em MVP operacional com backend multi-tenant, autenticação/RBAC/MFA administrativo, banco de dados, G|E Trust append-only, notificações transacionais, storage seguro e observabilidade. A plataforma de implantação (incluindo eventual Base44) só deve ser escolhida após passar pelos gates de segurança e portabilidade definidos no projeto.
